# .github

This is the special [`.github` repository](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file) for the **Dexterity Systems** organization.

## Purpose

Files stored in this repository serve as **organization-wide defaults** for all repositories under `dexterity-systems` that do not define their own. This includes community health files and other configuration that GitHub recognizes at the organization level.

## Supported default files

| File | Description |
|---|---|
| `CODE_OF_CONDUCT.md` | Standards for community behavior |
| `CONTRIBUTING.md` | Guidelines for contributing to our projects |
| `SECURITY.md` | How to responsibly report security vulnerabilities |
| `SUPPORT.md` | How to get help with our projects |
| `FUNDING.yml` | Sponsorship information |
| `profile/README.md` | Organization profile displayed on the GitHub org page |
| `.github/ISSUE_TEMPLATE/` | Default issue templates |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default pull request template |

## How it works

When a repository in the `dexterity-systems` organization does not contain one of the above files, GitHub automatically falls back to the version stored here. This allows us to maintain consistent community standards across all our repositories from a single place.

For more information, see the [GitHub documentation on default community health files](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
